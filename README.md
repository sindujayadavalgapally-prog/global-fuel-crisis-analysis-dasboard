# Global Fuel Crisis Analysis Dashboard

This project is a Power BI dashboard built using a global fuel crisis dataset.

## Features

- KPI Metrics (Global Average Price, Supply Deficit, Inflation Impact,year,renewablwuswage,fuel price,country,)
- Price Trends by Region and Fuel Type
- Geopolitical Event Impact Analysis
- Supply vs Demand Forecasting
- Interactive Filters

## Tool Used

- Power BI

## Purpose

To analyze global fuel market performance, track supply chain disruptions, and provide insights for economic decision-making.
